# Prompts used to build this portal

Send these to Claude Code in order, one message at a time. Messages 2–9 were sent while the work
was already running; sending them all at the start also works.

1. I want to create LeetCode-style practice for learning time series analysis. Assume a learner
   with no experience or knowledge of time series. After following the learning portal, they
   should master time series and pass a time series ML engineer interview and online test.
   Besides LeetCode-style tests, it must include good learning materials that a person can
   understand in one pass, especially non-native English readers. Design the learning experience
   with the best-known academic methods for teaching online students.

2. Save tokens: Opus does the planning, research and implementation design, Sonnet implements,
   and Haiku checks and reports.

3. Make sure it covers all the important, common and trending topics in time series. The final
   result must be deployable to any static-pages-only server.

4. Also include high-profile time series projects, ideas, thoughts and essential concepts in the
   tests. Create the design and plan first, then track implementation status against the plan.

5. Plan in any special skills that company interviewers are likely to appreciate.

6. Are there good free, open-source time series libraries that are worth studying and valuable?
   Include them too.

7. Also cover knowledge for expert engineers, up to staff level.

8. Check the latest 2026 time series trends and company requirements.

9. If there are Kaggle competitions for time series worth practicing, include a tutorial for each
   Kaggle exercise (if not, skip Kaggle).

10. Where can we host it? Can you host it on Claude Artifacts as a page once it is ready?

11. If it is on Claude Artifacts, we can enable an AI chatbot. Research this once the first round
    is complete.
